removeapp

Desktop app local for macOS to find and remove app leftovers.

Quick start

1. Activate virtual env:
   source .venv/bin/activate
2. Install deps:
   pip install -r requirements.txt
3. Run:
   PYTHONPATH=src python -m removeapp.main

Notes

- This is a local tool for your Mac.
- Some system paths require elevated permissions.
- By default, files are sent to Trash unless permanent delete is checked.
